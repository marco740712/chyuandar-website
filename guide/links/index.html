在地與南部機場

從高鐵臺南站

  • 搭 H31 高鐵接駁巴士 直達機場，約 20–30 分鐘一班
  • 或搭計程車，約 20 分鐘

從台南火車站／市區

  • 搭 105 號公車（經成功大學、台南火車站、新光三越新天地）

其他路線

  • 紅 3、8046、高雄客運 239 等（班次較少，請先查時刻表）

高雄國際機場小港機場
KHH

台南直達（最省事）

  • 搭 台灣好行 111 臺南小港機場線，從台南市區直達高雄機場，一天約 8 班

搭捷運

  • 高雄捷運紅線 → R4 高雄國際機場站
  • 2 號出口通往國內線，6 號出口通往國際線

從台南搭車轉乘

  • 台鐵：台南車站 → 高雄車站 → 捷運紅線往小港 → R4
  • 高鐵：左營站 → 捷運紅線往小港 → R4（約 28 分鐘）
